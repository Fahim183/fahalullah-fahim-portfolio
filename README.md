# Fahalullah Fahim - Full-Stack Motion Portfolio 
# Live Link: https://fahalullah-fahim-portfolio.vercel.app/

An interactive, responsive developer portfolio application showcasing projects, technical skills, academic credentials, and interactive canvas components.

## 🚀 How to Run in VS Code

1. Install **Node.js** from [nodejs.org](https://nodejs.org/).
2. Create a folder named `fahim-portfolio` on your computer and open it in **VS Code**.
3. Create all files according to the folder structure and paste their respective code blocks into them.
4. Open the VS Code Terminal (`Ctrl + ~`) and install all required dependencies:
   ```bash
   npm install
   ```
5. Launch the local Vite development server:
   ```bash
   npm run dev
   ```
6. Open your browser and go to `http://localhost:3000` (or `http://localhost:5173`).
